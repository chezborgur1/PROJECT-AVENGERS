# FCC wireless domain names (CAN-SPAM s.14; 47 CFR 64.3100)
#
# Commercial email to a domain on the FCC's wireless domain list needs the
# recipient's express prior authorization, which cold outreach never has, so
# the engine never sends to these domains (src/contacts/verify.ts marks them
# invalid; src/compliance/jurisdiction.ts blocks them). See
# docs/research/compliance.md section 1, item 12.
#
# STATUS: NOT THE OFFICIAL LIST. Compiled 2026-10-18 from well-known US
# carrier SMS/MMS gateway domains, because www.fcc.gov was unreachable from
# the build container (DNS failure and a proxy 403). Before the first send,
# and then every month, replace this file with the current list from
# https://www.fcc.gov/consumer-governmental-affairs/policy-divisions/consumer-policy-division/wireless-domain-names
# (the FCC's downloadable domain list file). A newly listed domain has a
# 30-day safe harbor, so a monthly refresh keeps the engine inside it.
