# Examples

Output of `npm run demo` on the fictional sample deal, Project Ridgeline
(`samples/project-ridgeline/`), plus the bot overview.

- `AMB Material Bot - Capabilities, Use Cases and Roadmap.pdf`: what the bot does, its limits and roadmap
- `project-ridgeline/`: the financial model (.xlsx), the CIM (.pptx and .pdf), `open-questions.md` and `run-summary.md`

Everything here is fictional. Real client outputs go to `output/`, which is git-ignored.
